# ATOK Unicode 辞書

ATOK で絵文字・数学記号・アクセント付き文字を変換入力するための単語辞書です。

ATOK は `(^_^)` のような顔文字は変換できますが、`😀` `∑` `ℝ` `x²` `é` のような文字は通常の変換ではほとんど候補に出ません。この辞書を取り込むと、コロンに続けて読みを打つことでこれらを変換できるようになります。

```text
:わらう    → 😀                  :Infty    → ∞            :E  → È É Ê Ë Ē …
:はーと    → ❤️ 💙 💚 💛 💜 …      :Leqslant → ⩽            :B  → 𝔹 ℬ 𝔅 𝐁 𝐵 …
:ゆびさし  → 👆 👇 👈 👉          :Alpha    → Α α 𝚨 𝛂 …    :^2 → ²
```

数学記号の読みには TeX のコマンド名を使います。書体やアクセント、色、向きが違うだけの文字は、元の文字や名前を打って候補から選びます。

## インストール

### 1. 単語ファイルをダウンロードする

[Releases](../../releases) の最新版から、必要な単語ファイルを取得します。

| ファイル | 内容 | 語数 |
| --- | --- | --- |
| `atok-all.txt` | 下の 3 つをすべて含む | 4,305 |
| `atok-emoji.txt` | 絵文字 | 539 |
| `atok-math.txt` | 数学記号・技術記号・ギリシャ文字・数学用の書体・関数名 | 3,402 |
| `atok-accent.txt` | アクセント付きラテン文字 | 364 |

3 つの単語ファイルは内容が重複していません。すべて使う場合は `atok-all.txt` だけを取り込んでください。

### 2. ATOK の設定を変更する

読みの英字は `:Infty` のように大文字で始めます。ATOK は大文字を打つと英語入力モードに切り替わり、初期設定ではこのモードのスペースバーが変換ではなく空白の入力になります。

ATOK プロパティ（Ctrl+F12）の［入力・変換］タブで［英語］を開き「英語入力ではスペースバーで空白を入力する」をオフにしてください。

### 3. 辞書を作って単語ファイルを取り込む

1. 辞書ユーティリティの［辞書］→［新規作成］で、`unicode-emoji.dic` などの辞書を作ります
2. ATOK プロパティの［辞書・学習］タブで、辞書セット一覧から**標準辞書セット**を選び、
   ［辞書の追加・削除］で作った辞書を追加します
3. 辞書ユーティリティの［一括処理］→［単語一括処理］で、**登録先に作った辞書を指定して**
   単語ファイルを読み込みます

専用の辞書に取り込んでおくと、不要になったときに辞書セットから外すだけで無効にできます。

### 変換できないとき

- 作った辞書を辞書ユーティリティで開き、語が入っているか確認してください。空の場合は、
  手順 3 で登録先を指定し忘れて、標準のユーザー辞書に登録されています。
- 辞書を標準辞書セット以外（辞書セット 7〜0 など）に追加した場合、スペースバーでは
  変換されません。
- 大文字から始まる読みで空白が入る場合は、手順 2 の設定を確認してください。

Releases の `atok-probes.zip` には、ATOK がどの読みや文字を受け付けるかを確かめるための
小さな単語ファイルが入っています。

## 使い方

ひらがな入力のまま、コロンキーに続けて読みを打ち、スペースバーで変換します。コロンは
全角の `：` になります。

| 入力したいもの | 読み | 例 |
| --- | --- | --- |
| 絵文字 | ひらがなの呼び名 | `:わらう` → 😀、`:いいね` → 👍 |
| 記号 | TeX のコマンド名 | `:Infty` → ∞、`:Leqslant` → ⩽ |
| 記号 | 日本語の読み | `:そうわ` → ∑、`:むげんだい` → ∞ |
| 上付き・下付き | `^` か `_` に続けて文字 | `:^2` → ²、`:_I` → ᵢ |
| ギリシャ文字 | TeX のコマンド名 | `:Alpha` → Α α |
| 数学用の書体 | 元の文字 | `:B` → 𝔹 ℬ 𝔅 𝐁 … |
| アクセント付き文字 | 元の文字 | `:E` → È É Ê Ë … |
| 関数名 | 関数の名前 | `:Sin` → 𝑠𝑖𝑛 𝐬𝐢𝐧 𝗌𝗂𝗇 𝚜𝚒𝚗 |

TeX のコマンド名は、最初の英字だけを大文字にして打ちます（`\infty` は `:Infty`、`\mapsto` は `:Mapsto`）。小文字から打つと、ATOK がローマ字をかなに変換してしまうためです。大文字と小文字だけが違うコマンド名（`\alpha` と `\Alpha` など）は、同じ読みの候補として並びます。

書体・アクセント・色・向きだけが違う文字には、それぞれの読みを用意していません。`:はーと` で各色のハートが、`:B` で 13 書体の B が候補に並ぶので、そこから選びます。一度選んだ候補は、ATOK の学習によって次から上位に表示されます。

## 制約

- ATOK Passport for Windows で動作を確認しています。ほかの製品や OS では確認していません。
- 半角英数入力モードでは変換できません。ATOK の仕様です。全角英数入力モードでの動作は確認していません。
- 全部入りの辞書では、母音の読みの候補が 50 個を超えます（`:O` は 58 個）。数学用の書体と アクセントの候補が同じ読みに並ぶためです。気になる場合は `atok-math.txt` と `atok-accent.txt` のどちらかだけを取り込んでください。
- `:Hat` `:Vec` などで入力されるアクセント記号は結合文字です。直前の文字と組み合わさります（`x` に続けて `:Vec` で `x⃗`）。
- 肌の色や性別を組み合わせた絵文字（ZWJ シーケンス）は収録していません。
- 数学用の書体の文字は、表示するフォントによっては □ になります。
- ATOK Passport の ATOK Sync One は、初期設定でユーザー作成辞書も同期します。 ほかの端末に同期したくない場合は、取り込む前に同期の設定を確認してください。

## 収録内容

### 絵文字

306 字の絵文字を、ひらがなの呼び名で引けます。呼び方が複数ある絵文字には、それぞれの
読みを用意しています（😀 は `:わらう` `:にこにこ` `:えがお`）。色や向きだけが違う絵文字は、
1 つの読みにまとめています。

| 読み | 候補 |
| --- | --- |
| `:はーと` | ❤️ 💓 💖 💙 💚 💛 💜 🖤 🤍 |
| `:ゆびさし` | 👆 👇 👈 👉 |
| `:ぐらふ` | 📈 📉 📊 |
| `:かぎ` | 🔐 🔑 🔒 🔓 |

### 数学記号

| 種類 | 内容 | 例 |
|---|---|---|
| TeX の記号 | LaTeX と AMS のコマンド名（約 1,500） | `:Sum` ∑、`:Subseteq` ⊆、`:Forall` ∀、`:Mapsto` ↦ |
| 日本語の読み | よく使う演算子・関係・矢印・単位・技術記号・図形 | `:せきぶん` ∫、`:ならば` ⇒、`:まる` ● ○ ◎ ◯ |
| 上付き・下付き | 数字・英字・ギリシャ文字・`+` `-` `=` | `:^-1` ⁻¹、`:^T` ᵀ ᵗ、`:_N` ₙ |
| ギリシャ文字 | 24 字の大文字と小文字、異体字 | `:Lambda` Λ λ、`:Varepsilon` ε ϵ |
| 数学用の書体 | 英字・数字・ギリシャ文字の 13 書体 | `:R` ℝ ℛ ℜ 𝐑 …、`:1` 𝟙 𝟏 … |
| 関数名 | `\sin` `\lim` `\det` や `argmax` `softmax` など 119 語 | `:Argmax` 𝑎𝑟𝑔𝑚𝑎𝑥 𝑎𝑟𝑔 𝑚𝑎𝑥 … |

数学用の書体は、二重線体・筆記体・太字筆記体・ひげ文字・太字ひげ文字・太字・斜体・太字斜体・サンセリフ・サンセリフ太字・サンセリフ斜体・サンセリフ太字斜体・等幅の 13 種です。数字とギリシャ文字は、Unicode に文字がある書体だけを収録しています。

### アクセント付き文字

アクセント付きのラテン文字を、元の文字の読みで引けます。

```text
:E → È É Ê Ë Ē Ĕ Ė Ę Ě …
:O → Ò Ó Ô Õ Ö Ø Ō Ő Œ …
```

フランス語・ドイツ語・北欧語・東欧語などで使うアクセントと、ベトナム語で使う符号を含みます。æ ß ð þ ŋ ə ı などの文字は、関係の深い文字の読みに入れています（æ は `:A`、ß は `:S`）。

## 語彙の追加とビルド

### ビルド

Python 3.10 以上で動きます。外部ライブラリは使いません。

```bash
python build.py
```

`dist/` に単語ファイルができます。`--level standard` または `--level full` で収録する記号を増やせます。大文字から始まる読みが使えない環境では、`--reading kana` を指定するとローマ字入力後のかなの綴り（`:いんｆｔｙ` など）で読みを登録します。オプションの一覧は `python build.py --help` で確認できます。

### 語彙の追加や読みの変更

絵文字は `data/emoji.tsv`、日本語の読みで引く記号は `data/symbols.tsv` に書きます。1 行が 1 エントリで、タブ区切りです。

```text
よみ1,よみ2<TAB>文字<TAB>分類<TAB>備考
```

- 読みにはコロンを書きません。ビルド時に付きます。
- 呼び方が複数ある文字には、読みをカンマ区切りで並べます。
- 色や向きだけが違う文字は、新しい読みを作らず、既存の読みに並べます。ほかの行と読みが同じでも構いません。

TeX のコマンド名の対応表は `data/tex-symbols.tsv` で、`tools/gen_tex_symbols.py` が
自動で生成します。数学用の書体・アクセント付き文字・上付き下付きは、`build.py` が
Unicode の文字名から生成します。

### リリース

`main` ブランチに push すると、GitHub Actions がビルドと検査を行い、Releases に公開します。
検査には `tools/verify_dist.py` を使います。手元では `python tools/verify_dist.py dist` で
同じ検査ができます。
